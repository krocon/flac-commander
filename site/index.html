A2 the engine · Rust

The sound never waits for the window.

Decoding runs on its own thread and hands the samples over through a lock-free ring buffer. The audio callback takes no lock, allocates nothing and touches no file, so a busy window cannot make the music stutter.

40skins come with the app, more as a ZIP
8formats, each one proven by a test on a real file

gapless

An album is one piece

The next track is decoded before the current one ends. Live albums and classical movements run into each other as they were recorded.

position

The time you see is the time you hear

The position counts what the callback has really put out, not what was decoded. It never runs ahead and it stands still in pause.

robust

A broken file is not the end

Files that cannot be played are marked and skipped. If the audio device disappears, playback pauses at its position and goes on with the new device.

A3 skins · 40 included

Pick the machine you grew up with.

Turntable, cassette deck, tape machine, pocket player, receiver, synthesiser. Every skin is a complete player with its own layout, and switching takes one key: ⌘K or Ctrl+K.

The pictures show the app as it is: each one is the preview that ships inside the skin.

A4 skin format · version 1

A skin is data, not a program.

A ZIP with a skin.json and pictures. No JavaScript, no HTML, no free CSS: a skin chooses values and arranges the parts the app provides. That is why you can install one from anywhere.

  1. Skins change the look, never the logic. What a key does and how a slider is read out to a screen reader is the same in every skin.
  2. An invalid skin is refused as a whole. The check runs in Rust before anything is shown and names every violation at once.
  3. There is always a way back. ⌘0 or Ctrl+0 returns to the default skin, whatever the current one looks like.
  4. Winamp skins come along. A classic .wsz is converted on import: main window, keys and colours. It is a conversion, not a pixel-exact copy.

⌘L · playlist

Drop a folder, press space

Add files with the dialog, drop files and folders on the window or pass them on the command line. Title, artist and length come from the tags.

⌘B · library

Your folders are the library

Choose a music folder and walk through it: albums as a grid of covers, a search over folder, album, artist and title. Play at once or add to the playlist. No database, no import.

⌘E · equalizer

Ten bands, at once

Every move of a slider is heard immediately. The equalizer runs inside the audio callback.

restart

It remembers

Playlist, the current track with its position, volume, repeat, shuffle, the skin, the places of the windows and the folder of the library.

visualizer

A spectrum in every skin

Bars, meters and needles move with the music, and stay still when your system asks for reduced motion.

not there yet

What version 0.1 cannot do

Reordering the playlist and selecting several titles. The library does not sort by year and has no view of all albums of one artist across folders. The import of Winamp skins covers the main window only.
